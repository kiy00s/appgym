# GymTracker PWA

This is a mobile-first Progressive Web App (PWA) built with **React**, **Vite**, and **TypeScript**, designed for iOS Safari (*Add to Home Screen*) and deployed on **GitHub Pages**.

## Rules
- Mobile-first, responsive touch-friendly layout tailored for iPhone viewports.
- Standalone PWA offline support using Service Worker and LocalStorage / IndexedDB.
- Run `npm run build` and typecheck before declaring tasks done.
- Vite base path must remain relative (`base: './'`) to allow hosting under any GitHub Pages repository subpath.
